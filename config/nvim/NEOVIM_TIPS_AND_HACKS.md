# Neovim 技巧、Hack 与文本处理手册

本文适合已经完成 [Neovim 场景化新手指南](./NEOVIM_BEGINNER_GUIDE.md) 的用户。需要快速查当前配置快捷键时参见 [Neovim / LazyVim 速查手册](./NEOVIM_CHEAT_SHEET.md)。

这里的重点不是收集冷门命令，而是用 Vim 原生组合能力解决真实文本问题。示例已经按当前 Neovim 环境设计，但批量修改前仍应先在小范围验证。

## 安全等级与使用原则

| 标记 | 含义 | 推荐动作 |
| --- | --- | --- |
| `[只读]` | 只移动、查看或计算，不修改 Buffer | 可以直接尝试 |
| `[可撤销]` | 修改当前 Buffer，可立即用 `u` 撤销 | 先缩小范围，再执行 |
| `[批量高风险]` | 覆盖整个 Buffer、多个文件或调用外部过滤器 | 先保存、预览并确认 Git 状态 |

执行批量命令前遵循四步：

1. `<C-s>` 或 `:write` 保存当前文件。
2. 先把 `%` 换成几行或 Visual 选区验证。
3. 替换命令优先使用 `c` 确认标志或 `n` 计数标志。
4. 确认 `u`、`:earlier` 或 Git 能恢复，再扩大范围。

## 一分钟就能用上的小技巧

### 保持上下文而不是只移动光标

| 目标 | 命令 | 安全等级 |
| --- | --- | --- |
| 当前行滚动到屏幕中央 | `zz` | `[只读]` |
| 当前行滚动到屏幕顶部 / 底部 | `zt` / `zb` | `[只读]` |
| 跳到屏幕顶部 / 中部 / 底部 | `H` / `M` / `L` | `[只读]` |
| 回到上次 Insert 位置 | `gi` | `[只读]` |
| 上一个 / 下一个修改位置 | `g;` / `g,` | `[只读]` |
| 配对括号 | `%` | `[只读]` |
| 打开光标下的文件路径 | `gf` | `[只读]` |
| 用系统程序打开路径或 URL | `gx` | `[只读]` |

长函数中执行 `gd` 跳走再返回时用 `<C-o>`；只想回到最近修改过的位置时用 `g;`，两者解决的问题不同。

### 少量编辑的快捷组合

| 目标 | 命令 | 安全等级 |
| --- | --- | --- |
| 交换当前字符和下一个字符 | `xp` | `[可撤销]` |
| 当前行下移 / 上移 | `ddp` / `ddkP` | `[可撤销]` |
| 合并下一行并插入空格 | `J` | `[可撤销]` |
| 合并下一行但不插入空格 | `gJ` | `[可撤销]` |
| 替换一个字符 | `r{char}` | `[可撤销]` |
| 连续覆盖字符 | `R` | `[可撤销]` |
| 当前字符切换大小写 | `~` | `[可撤销]` |
| 当前单词转小写 / 大写 | `guiw` / `gUiw` | `[可撤销]` |
| 数字增加 / 减少 | `<C-a>` / `<C-x>` | `[可撤销]` |

如果只是移动一行，本配置的 `<A-j>` / `<A-k>` 更直观；`ddp` 的价值是帮助理解删除、移动和粘贴本来就是可以组合的原生动作。

### Insert 模式也能少按几次 Escape

| 目标 | 命令 | 安全等级 |
| --- | --- | --- |
| 删除前一个单词 | Insert 模式 `<C-w>` | `[可撤销]` |
| 删除到本次插入的行首 | Insert 模式 `<C-u>` | `[可撤销]` |
| 临时执行一个 Normal 命令 | Insert 模式 `<C-o>{command}` | 取决于命令 |
| 插入寄存器内容 | Insert 模式 `<C-r>{register}` | `[可撤销]` |
| 插入计算结果 | Insert 模式 `<C-r>=expression<CR>` | `[可撤销]` |

例如在 Insert 模式输入 `<C-r>=21*2<CR>` 会插入 `42`；输入 `<C-r>%` 会插入当前文件名。

## 寄存器：解决“刚复制的内容被删除覆盖”

Vim 的删除和复制都会写入寄存器。先用 `:registers` 或 `:reg` 查看当前内容。

| 需求 | 命令 | 安全等级 |
| --- | --- | --- |
| 粘贴最近一次 yank，而不是最近删除 | `"0p` | `[可撤销]` |
| 删除但不覆盖默认寄存器 | `"_d{motion}` | `[可撤销]` |
| 复制到命名寄存器 `a` | `"ay{motion}` | `[只读]` |
| 粘贴命名寄存器 `a` | `"ap` | `[可撤销]` |
| 追加到寄存器 `a` | `"Ay{motion}` | `[只读]` |
| 读取系统剪贴板 | `"+p` | `[可撤销]` |

典型场景：先 `yiw` 复制一个变量名，随后用 `diw` 删除别处内容。此时普通 `p` 可能粘贴刚删除的内容，而 `"0p` 仍然粘贴那个变量名。

表达式寄存器可以直接计算或转换：

```vim
:put =strftime('%Y-%m-%d')
:put =expand('%:p')
```

第一条在下一行插入日期，第二条插入当前文件绝对路径。它们都属于 `[可撤销]`。

## 命令历史和搜索历史

| 目标 | 命令 | 安全等级 |
| --- | --- | --- |
| 打开 Ex 命令历史窗口 | `q:` | `[只读]` |
| 打开搜索历史窗口 | `q/` | `[只读]` |
| 在 `:` 命令行切到历史窗口 | `<C-f>` | `[只读]` |

历史窗口是普通 Buffer：可以用 `/` 搜索、用 `j/k` 选择、用 `<CR>` 执行。复杂替换写错时，打开 `q:` 修改上一条命令通常比重新输入更快。

## 先掌握 Ex 范围

Ex 命令的通用形式是：

```text
:{range}{command}
```

| 范围 | 含义 |
| --- | --- |
| `.` | 当前行 |
| `$` | 最后一行 |
| `%` | 整个文件，即 `1,$` |
| `10,20` | 第 10 到 20 行 |
| `.,+5` | 当前行到向下第五行 |
| `'<,'>` | 最近 Visual 选区 |
| `'a,'b` | 标记 `a` 到标记 `b` |

示例：

```vim
:10,20>
:.,+5sort
:'<,'>s/old/new/gc
:'a,'bnormal! ==
```

- 第一条缩进第 10 到 20 行。
- 第二条只排序当前行到向下第五行。
- 第三条只在 Visual 选区确认替换。
- 第四条重新缩进两个标记之间的每一行。

范围越小，风险越低。把已经验证的命令从 `'<,'>` 扩大到 `%`，比一开始就操作全文更安全。

## 查找替换进阶

### 安全替换模板

最适合新手的全文替换模板：

```vim
:%s/old/new/gc
```

常用标志：

| 标志 | 作用 |
| --- | --- |
| `g` | 每行替换全部匹配，而不只是第一个 |
| `c` | 每一项都确认 |
| `i` / `I` | 忽略大小写 / 强制区分大小写 |
| `n` | 只统计匹配数量，不修改 |
| `e` | 没有匹配时不报错 |

先统计再修改：

```vim
:%s/old/new/gn
:%s/old/new/gc
```

路径包含很多 `/` 时可以换分隔符：

```vim
:%s#/old/path/#/new/path/#gc
```

### 单词边界和大小写

```vim
:%s/\<cat\>/dog/gc
:%s/error/ERROR/gcI
:%s/legacy/modern/gci
```

第一条只替换完整单词 `cat`，不会误伤 `category`；第二条强制区分大小写；第三条忽略大小写。

也可以把大小写控制写进模式：`\c` 表示忽略大小写，`\C` 表示区分大小写。

### 捕获组和 very magic

Vim 默认正则与 PCRE、JavaScript 不完全相同。使用 `\v` 进入 very magic 模式后，捕获组和量词更接近常见正则写法：

```vim
:%s/\v([A-Za-z]+) ([A-Za-z]+)/\2, \1/gc
```

它会把：

```text
Ada Lovelace
```

变成：

```text
Lovelace, Ada
```

只想替换匹配中的一部分时使用 `\zs` 和 `\ze`：

```vim
:%s/api_\zsold\ze_v[0-9]/new/gc
```

它只把 `api_old_v2` 中间的 `old` 改为 `new`。

### 表达式替换

替换内容以 `\=` 开头时，后面可以写 Vim 表达式：

```vim
:%s/\d\+/\=submatch(0) + 1/gc
```

这会把所有十进制数字加一。先使用 `n` 标志确认匹配范围，避免同时修改版本号、日期或 ID。

根据内容决定替换结果：

```vim
:%s/\v(true|false)/\=submatch(0) ==# 'true' ? 'false' : 'true'/gc
```

### 多行匹配

`\_s` 可以匹配包括换行在内的空白：

```vim
:%s/foo\_s\+bar/foo bar/gc
```

它能把分布在一行或多行的 `foo ... bar` 合并。多行正则影响范围较难直观看清，必须保留 `c` 并逐项确认。

### 重复最近替换

| 命令 | 作用 |
| --- | --- |
| `:&&` | 在当前行重复最近替换并保留标志 |
| `g&` | 在整个文件重复最近替换 |

`g&` 属于 `[批量高风险]`；执行前先用 `:&&` 在一行验证，或从 `q:` 找回并显式编辑原命令。

## Global、Vglobal 与 Normal 的组合

通用形式：

```text
:[range]g/{pattern}/{command}
:[range]v/{pattern}/{command}
```

`g` 对匹配行执行命令，`v` 对不匹配行执行命令。

### 查看、保留和删除匹配行

```vim
:g/TODO/p
:g/^\s*$/d
:v/\v(ERROR|WARN)/d
```

- 第一条只打印包含 `TODO` 的行，属于 `[只读]`。
- 第二条删除空行或只有空白的行，属于 `[可撤销]`。
- 第三条删除不包含 `ERROR` 或 `WARN` 的日志行，属于 `[可撤销]`。

先用 `p` 预览：

```vim
:v/\v(ERROR|WARN)/p
```

确认打印出的正是准备删除的行，再把 `p` 改成 `d`。

### 对匹配行执行 Normal 命令

```vim
:g/^import /normal! A;
:g/TODO/normal! 0f:lD
```

第一条给每个 `import` 行追加分号。第二条只是展示组合能力：在包含 `TODO` 的行上定位冒号并删除其后内容。

这里使用 `normal!`，确保执行 Vim 原生命令，不受自定义映射影响。任何 `:global ... normal!` 都应视为 `[批量高风险]`，先把 `g` 的范围限制到 Visual 选区：

```vim
:'<,'>g/^import /normal! A;
```

### 复制匹配行到文件末尾

```vim
:g/TODO/t$
```

`:t` 是 `:copy` 的缩写。这会保留原行并在文件末尾复制所有匹配行，适合临时汇总，执行后可以整体复制结果再用 `u` 恢复文件。

## 排序、去重、连接和清洗

### 排序与去重

```vim
:%sort
:%sort!
:%sort i
:%sort n
:%sort u
```

| 命令 | 作用 |
| --- | --- |
| `:sort` | 升序排序 |
| `:sort!` | 降序排序 |
| `:sort i` | 忽略大小写排序 |
| `:sort n` | 按行首数字排序 |
| `:sort u` | 排序并删除重复行 |

这些命令均修改当前 Buffer。处理配置或清单时，先 Visual 选择目标区域，再执行 `:sort u`，避免打乱文件结构。

### 合并与拆分

```vim
:10,20join
:'<,'>join
:%s/,\s*/\r/gc
```

前两条连接指定行；第三条把逗号分隔内容拆成多行。真正的 CSV 可能包含引号、转义逗号和换行，不应使用简单正则处理，应交给了解 CSV 语法的外部工具。

### 清理尾随空格、空行和 CRLF

```vim
:%s/\s\+$//e
:g/^\s*$/d
:set list!
:set fileformat?
:set fileformat=unix
```

- 第一条删除行尾空白。
- 第二条删除所有空行，可能破坏段落结构，属于 `[批量高风险]`。
- `:set list!` 显示或隐藏 Tab、行尾等不可见字符。
- 修改 `fileformat` 后保存，可把 CRLF 文件转换为 Unix 换行。

只想删除每行末尾残留的 `CR` 字符时可以使用 `:%s/\r$//e`，但先确认文件不是需要保留 CRLF 的跨平台脚本。

`:retab` 可以按当前 `tabstop` 和 `expandtab` 重写 Tab/空格，可能产生大量 diff，除非明确了解项目缩进规则，否则不要对整个文件盲目执行。

## Visual Block：列编辑和连续编号

### 给多行添加相同前缀或后缀

1. 按 `<C-v>` 进入块选择。
2. 用 `j/k` 选择多行。
3. 按 `I` 输入前缀，或按 `A` 输入后缀。
4. 按 `<Esc>`，内容会应用到所有选中行。

适合批量增加 Markdown 列表符号、注释前缀或配置键前缀，属于 `[可撤销]`。

### 生成连续编号

假设多行都以 `1.` 开头：

1. 用 `<C-v>` 选中这些行中的数字 `1`。
2. 按 `g<C-a>`。

Neovim 会生成递增序列。普通 `<C-a>` 对全部选中数字增加相同数值，`g<C-a>` 才会形成序列。

### 修改固定列

块选择后按 `c` 可以替换同一列，适合对齐良好的表格或日志。对包含宽字符、Tab 或不等长行的内容，先打开 `:set list!` 检查真实列结构。

## 用外部命令过滤文本

外部过滤器的形式是：

```text
:{range}!{command}
```

过滤器会用命令输出替换选定范围，因此默认视为 `[批量高风险]`。

### 格式化 JSON

```vim
:%!jq .
```

它把整个 Buffer 交给 `jq` 并用格式化结果覆盖。若 JSON 无效，外部命令的错误输出可能进入 Buffer；执行前保存，失败时立即 `u`。

也可以只处理 Visual 选区：

```vim
:'<,'>!jq .
```

### 使用系统 sort 或其他过滤器

```vim
:'<,'>!sort
:%!python3 -m json.tool
```

Vim 自带 `:sort` 时应优先使用内建命令；外部 `sort` 的价值在于复用熟悉的命令行参数和 locale 行为。

### 把命令输出读入 Buffer

```vim
:read !date
:read !git log --oneline -10
:0read !rg --files
```

`:read !command` 在当前行后插入输出，`:0read` 插入文件顶部。这些操作均可用 `u` 撤销。

把现有文件内容读入当前 Buffer：

```vim
:read path/to/file
```

把 Visual 选区抽取为新文件：

```vim
:'<,'>write extracted.txt
```

如果目标文件已存在，Neovim 会拒绝覆盖；不要为了省事直接加 `!`，先确认目标路径。

只想把内容传给外部命令查看结果，而不替换 Buffer，可以用：

```vim
:%write !wc -l
```

## 宏、Quickfix 与跨文件批处理

### 把一个正确操作应用到选中行

录制宏 `a` 后，可以对 Visual 选中的每一行执行：

```vim
:'<,'>normal @a
```

也可以只在匹配行执行：

```vim
:g/pattern/normal @a
```

宏依赖光标位置和文本结构。先在两三行验证，并确保每次宏结束时光标位置一致。

### 建立 Quickfix 列表

```vim
:vimgrep /TODO/j **/*.lua
:copen
```

使用 `[q` / `]q` 浏览结果。`j` 表示收集全部匹配而不是在第一处停止。

### 先统计，再跨文件修改

在 Quickfix 涉及的每个文件中统计匹配：

```vim
:cfdo %s/old/new/gn
```

确认文件集合和数量后再修改：

```vim
:cfdo %s/old/new/gc | update
```

这是 `[批量高风险]`：

- `:cfdo` 对 Quickfix 中的每个文件执行一次，通常比对每个条目执行的 `:cdo` 更适合替换。
- `update` 会保存发生修改的文件。
- 执行前必须确认 Git 工作区，最好只针对可以整体回滚的提交范围。

其他批处理命令：

| 命令 | 范围 |
| --- | --- |
| `:cdo` | Quickfix 每个条目 |
| `:cfdo` | Quickfix 涉及的每个文件 |
| `:argdo` | Argument list 中每个文件 |
| `:bufdo` | 所有已加载 Buffer |

不要在不了解目标集合时直接追加 `| update`。先运行 `:args`、`:buffers` 或打开 Quickfix 检查范围。

## 特殊场景配方

### 从大量日志中只保留错误和警告

先预览将要删除的行：

```vim
:v/\v(ERROR|WARN)/p
```

确认后删除：

```vim
:v/\v(ERROR|WARN)/d
```

再用 `:%sort u` 去重。如果日志顺序本身有意义，不要排序，只做删除或复制。

### 从日志中提取唯一 ID

原始内容：

```text
2026-08-01 INFO user_id=abc123 action=login
2026-08-01 INFO user_id=xyz789 action=logout
```

提取并去重：

```vim
:%s/\v.*user_id=([^ ]+).*/\1/
:%sort u
```

第一条会把不符合格式的行原样保留。处理混合日志时先用 `:v/user_id=/p` 找出异常行。

### 格式化或压缩 JSON

格式化：

```vim
:%!jq .
```

压缩成单行：

```vim
:%!jq -c .
```

若只想检查合法性而不改 Buffer，可以打开终端运行 `jq empty file.json`。

### 批量添加配置前缀

规则一致且列对齐时使用 Visual Block + `I`。行结构不一致时使用捕获组：

```vim
:%s/\v^([A-Za-z_][A-Za-z0-9_]*)=/APP_\1=/gc
```

确认模式不会匹配注释或已经存在前缀的键。

### 检查换行、编码和 BOM

```vim
:set fileformat?
:set fileencoding?
:set bomb?
:set list!
```

这些都是 `[只读]`。需要转换时只修改明确的选项并保存，例如 `:set fileformat=unix`。编码转换前保留原文件或 Git 快照。

### 处理 Git diff 和冲突

在 diff 模式下：

| 目标 | 命令 |
| --- | --- |
| 下一个 / 上一个差异 | `]c` / `[c` |
| 从另一个窗口取得当前差异 | `do` 或 `:diffget` |
| 把当前差异发送到另一个窗口 | `dp` 或 `:diffput` |
| 重新计算 diff | `:diffupdate` |

`do`/`dp` 的方向取决于当前窗口。第一次处理冲突时优先使用 `<leader>gg` 打开 Lazygit，确认左右两侧含义后再操作。

### 从当前内容生成临时报告

1. 用 `<leader>fn` 新建空 Buffer。
2. 用 `:read !git status --short` 插入 Git 状态。
3. 用 `:read !git log --oneline -10` 插入最近提交。
4. 整理后用 `:write report.md` 保存。

这适合生成排障记录、发布说明草稿或代码审阅上下文。

### 临时打开超大日志

插件和语法分析可能让超大文件变慢，可以从终端使用：

```sh
nvim --clean -R huge.log
```

`--clean` 不加载当前 LazyVim 配置，`-R` 使用只读模式。只需搜索和查看时，这比在正常项目会话中加载所有语言能力更稳妥。

## 撤销、恢复和失败处理

| 情况 | 命令 |
| --- | --- |
| 撤销最近修改 | `u` |
| 重做 | `<C-r>` |
| 查看撤销分支 | `:undolist` |
| 回到五分钟前 | `:earlier 5m` |
| 回到五分钟后 | `:later 5m` |
| 放弃当前未保存修改并重载 | `:edit!` |
| 查看最近消息和错误 | `:messages` |

批量命令失败后的处理顺序：

1. 不要继续编辑，先按 `u` 判断能否整体撤销。
2. 使用 `:undolist` 和 `:earlier` 找到执行前状态。
3. 如果命令已写入多个文件，立即检查 Git diff，再决定逐个恢复或整体回滚。
4. 如果外部过滤器把错误输出写入 Buffer，先 `u`，再到终端单独验证命令。

`:edit!` 会丢弃当前 Buffer 所有未保存修改，只应作为明确的恢复手段，而不是普通撤销方式。

## 推荐的练习清单

在临时文件中完成以下练习：

1. 使用 `:%s/old/new/gn` 统计，再用 `gc` 确认替换。
2. 用捕获组交换两列文本。
3. 用 `:v/pattern/d` 只保留需要的日志行。
4. 用 Visual 范围执行 `:sort u`。
5. 用 `<C-v>` + `I` 给多行添加前缀。
6. 用 `g<C-a>` 生成连续编号。
7. 用 `:%!jq .` 格式化一段 JSON，再用 `u` 恢复。
8. 用 `q:` 找回并修改刚才的替换命令。
9. 用 `:undolist`、`:earlier`、`:later` 在修改历史中移动。

完成这些练习后，你应该能从“记快捷键”进入“组合范围、模式和命令解决文本问题”的阶段。

继续深入可阅读：`:help :range`、`:help :substitute`、`:help pattern`、`:help :global`、`:help :normal`、`:help registers`、`:help visual-block`、`:help quickfix` 和 `:help undo-branches`。
